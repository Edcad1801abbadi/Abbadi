

# خطة إصلاح الاتصال الصوتي وعرض المتصلين

## المشاكل المكتشفة

### 1. الصوت لا يعمل أبداً بين جهازين
السبب الرئيسي: **مشكلة Autoplay على المتصفحات** - المتصفحات الحديثة (خاصة على الجوال) تمنع تشغيل الصوت تلقائياً بدون تفاعل المستخدم. حالياً الكود ينشئ `new Audio()` ويحاول `audio.play()` بدون أي تفاعل مستخدم مسبق، فيتم حظره صامتاً.

### 2. نظام الهدف (عام/خاص) مكسور
- عند اختيار سيارة من القائمة (`handleSelectVehicle`) يتم فقط تغيير `selectedTarget` كعنوان نصي، لكن **لا يتم إنشاء اتصال خاص فعلي** (لا يتغير `privateCallTarget`)
- عند تفعيل المكالمة الخاصة، المدرب ينتقل لقناة خاصة لكن **السيارة تبقى على القناة العامة** ولا تنتقل، فلا يسمع أحدهما الآخر

### 3. تدمير الميكروفون عند تبديل القناة
عند تغيير `privateChannelId` أو `roomCode`، يتم cleanup كامل بما في ذلك `localStreamRef.current?.getTracks().forEach(t => t.stop())` مما يوقف الميكروفون ويحتاج إعادة طلب إذن

## الحل المقترح

### المهمة 1: إصلاح تشغيل الصوت (Autoplay Fix)
- إضافة وظيفة `unlockAudio` تُنفذ عند أول تفاعل مستخدم (ضغط PTT أو أي زر)
- تشغيل AudioContext مؤقت لفتح قفل الصوت
- استخدام `audio.play()` مع معالجة صحيحة للأخطاء وإعادة المحاولة
- إضافة مؤشر بصري إذا فشل تشغيل الصوت

### المهمة 2: إصلاح نظام العام/الخاص
**الوضع العام (افتراضي):**
- الجميع على نفس القناة (`room-{area}`) يسمعون بعضهم عند PTT
- إزالة مفهوم `selectedTarget` النصي المربك

**الوضع الخاص:**
- عند ضغط المدرب على سيارة معينة من "سيارات متصلة"، يُرسل طلب مكالمة خاصة عبر القناة العامة
- **تغيير الهيكل**: بدلاً من تغيير القناة بالكامل، يتم كتم الصوت من/إلى باقي الأجهزة وتفعيله فقط مع الطرف المطلوب (Selective Mute)
- هذا يحل مشكلة أن السيارة لا تنتقل للقناة الخاصة

### المهمة 3: حفظ الميكروفون عبر تبديل القنوات
- فصل دورة حياة الميكروفون عن دورة حياة القناة
- عدم إيقاف tracks عند تبديل القناة، فقط إغلاق peer connections وإعادة التفاوض

### المهمة 4: تحسين عرض المتصلين
- عرض قائمة واضحة ومنفصلة: "سيارات متصلة" و"مدربين متصلين" في كلا الواجهتين
- إضافة مؤشر الوضع الحالي (عام/خاص) بوضوح في الشاشة الرئيسية

## التفاصيل التقنية

### تغييرات `useWebRTC.ts`:

```text
┌─────────────────────────────────────────┐
│  useWebRTC (معدّل)                      │
│                                         │
│  1. فصل الميكروفون (ref مستقل)          │
│  2. Audio unlock عند أول تفاعل          │
│  3. Selective mute بدل تغيير القناة     │
│  4. ICE restart عند الانقطاع            │
└─────────────────────────────────────────┘
```

**Selective Mute للمكالمات الخاصة:**
- بدل `privateChannelId` الذي يغير القناة بالكامل، نضيف `privatePeerId` state
- عند تفعيله: نكتم جميع remote audio elements ما عدا الطرف المحدد
- عند تفعيل PTT: نُعلم فقط الطرف المحدد (عبر broadcast مع فلترة)

**Audio Unlock:**
```text
onPointerDown (أول مرة) → AudioContext.resume() → 
  remoteAudios.forEach(a → a.play())
```

### تغييرات `InstructorRadio.tsx`:
- إزالة `selectedTarget` المربك واستبداله بـ `privatePeerId`
- إضافة مؤشر واضح: "🔊 بث عام" أو "🔒 خاص مع سيارة XXXX"
- عند الضغط على سيارة في "سيارات متصلة" → تفعيل الوضع الخاص
- زر إنهاء → العودة للوضع العام

### تغييرات `StudentCarScreen.tsx`:
- إضافة audio unlock عند أول ضغط PTT
- عرض مؤشر إذا المدرب في وضع خاص مع هذه السيارة
